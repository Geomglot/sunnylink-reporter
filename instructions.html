Sunnylink Settings Reporter

How to use the extension

Getting started

  1. Log into sunnylink.ai in Chrome as you normally would.
  2. Open the extension by clicking its toolbar icon. If you do not see it, click the puzzle-piece icon near the top-right of Chrome and pin Sunnylink Settings Reporter.

Buttons

  • Crawl All Pages - opens a new tab and automatically visits every settings page (selecting your device if asked), drilling into sub-panels such as MADS and Torque Settings. When it finishes it shows the compiled report in that same tab. Watch the toolbar badge for progress: a rising count while scanning, then a green OK when done.
  • Rescan Current Page - re-scans the sunnylink page you are currently viewing. Useful after changing a setting.
  • Open Full Report - opens the compiled report in a new tab at any time.
  • Instructions - opens this page.
  • Clear Saved Data - deletes the stored report so you can start fresh.

Reading the report

  • Cards are laid out in the same order as the sunnylink left-hand menu.
  • Click a card's title to open that settings page - it reuses the tab you launched the crawl from (or an existing sunnylink tab) rather than opening a new one.
  • Values of On are shown in green and Off in red for quick scanning.
  • Settings that cannot currently be changed (greyed out on the dashboard) are shown in a paler colour.

Good to know

  • The crawl needs one visible tab for its duration - do not close that tab while it runs. It takes roughly 30-60 seconds.
  • Everything stays on your machine. Nothing is uploaded, shared, or tracked.
  • If a page's live values have not loaded yet (device briefly offline), that page is skipped rather than recorded as "Connecting..." - just re-crawl once the device is back online.
